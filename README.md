### 🤖 [CareerPilot AI](https://github.com/deepakdeore5650/CareerPilot-AI)
**AI-Powered Resume Analysis & Career Guidance Platform**

A full-stack AI career development platform where users upload a resume and get an AI-driven ATS score, missing-skill detection, and resume feedback, plus a personalized AI mentor dashboard for career guidance, skill-gap analysis, and learning roadmaps — powered by Google Gemini AI.

| | |
|---|---|
| ⭐ **Key Features** | JWT + Google OAuth 2.0 auth · AI resume parsing & ATS scoring · AI mentor dashboard with skill-gap analysis · Job recommendations based on resume + skills · Full resume & mentor history tracking · Email OTP verification (Gmail SMTP / Brevo) |
| ⚙️ **Tech Stack** | Spring Boot · Spring Security · Hibernate/JPA · React.js · Framer Motion · MySQL · Google Gemini AI · JWT |
| 🏗️ **Architecture** | Decoupled REST backend (Spring Boot) + React/Vite SPA frontend, with AI resume parsing and OAuth2 identity flows |
| 📱 **Design** | Glassmorphism UI, animated dashboard, fully responsive |

### 🏠 [Local Service Provider](https://github.com/deepakdeore5650/LocalService-Provider)
**Verified Local Services Booking Platform**

A three-sided booking platform connecting users with admin-verified local service professionals (electricians, plumbers, technicians). Service providers can't go live until an admin manually approves them, and every booking flows through a real Razorpay payment integration.

| | |
|---|---|
| ⭐ **Key Features** | Admin verification flow for providers (INACTIVE → ACTIVE) · Razorpay payment gateway (UPI/Card/Net Banking) with signature verification · Booking accept/reject workflow for providers · Reviews & ratings · Built-in chatbot for user support |
| ⚙️ **Tech Stack** | Spring Boot · Spring Security · Spring MVC · Hibernate/JPA · MySQL · React · Bootstrap · Razorpay API |
| 🏗️ **Architecture** | Role-based access control across User / Provider / Admin, with a dedicated admin approval gate before providers can receive bookings |
| 📱 **Design** | Responsive React frontend with a dedicated booking & payment flow |

### 🧬 [HealthTrack+](https://github.com/Durvesh-code/HealthTrack-) <sub>· team project</sub>
**Unified Health OS connecting Patients, Doctors & Pharmacies**

A tripartite healthcare ecosystem built with a team (`getch();`) that replaces fragmented health records with one role-aware platform — live prescription routing between doctors and pharmacies, an AI health assistant with tool-calling, and wearable vitals synced from Google Fit.

| | |
|---|---|
| ⭐ **Key Features** | Role-aware AI chat assistant (Agno framework, OpenAI models) with memory & tool calling · NumPy-vectorized hospital finder (50,000+ records in ~1–3ms) · QR-based prescription transfer to pharmacies · Google Fit OAuth2 vitals sync (heart rate, steps, sleep) · Live pharmacy inventory & dispense queue |
| ⚙️ **Tech Stack** | React 18 + Vite · Python · Flask + Flask-JWT-Extended · MySQL · MongoDB · OpenAI (GPT-4o-mini) · Google Maps API · Google Fit REST API |
| 🏗️ **Architecture** | Role-based SPA over a Flask REST API, dual-database design (MySQL for core records, MongoDB for time-series vitals & AI session memory) |
| 📱 **Design** | Glassmorphism UI with role-specific dashboards for Patients, Doctors, and Pharmacies |
